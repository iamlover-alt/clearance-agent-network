# Clearance

Agent network for thirty legal creative tools. Compose a chain, run the handoffs, and package the run as files you can commit.

This repository is the network: the catalog, and six workflows ready to extend. The Clearance console is where a run gets packaged.

## Workflows

- **Ship a site** — Research, diagram, interface, code, deploy, deck.
- **Product film** — Still, two motion desks, cutdowns, a presenter.
- **Meeting to memo** — Transcript, doc, long edit, public draft.
- **Song drop** — Write it, tag it, read the hook.
- **Photo finish** — Clean light, erase, upscale, cut out.
- **Research desk** — Sources, the code angle, a model check, the close.

## Catalog

Thirty agents across picture, motion, voice, sound, code, search, and words. Each entry in [`catalog/agents.json`](catalog/agents.json) links to the real product.

Clearance writes the handoff. It does not call the vendor, and it does not impersonate someone who did not agree.

## A run

After a run, the GitHub desk downloads a bundle: a README, `workflow.json`, and one markdown file per agent. Commit that folder here, next to `catalog/`.
